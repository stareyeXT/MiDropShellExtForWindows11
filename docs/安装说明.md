# 安装说明

本文把「从零到右键可用」拆成可以直接复制的命令。**第 3 节是实测过的**（2026-11-10，Windows 11 26300.9711 + 小米电脑管家 6.0.2.30），第 7 节「正式安装进 `MiSmartShare\`」需要管理员权限，按项目约束**未实测**。

---

## 1. 前置条件

| 项 | 要求 | 本机实测值 |
|---|---|---|
| 系统 | Windows 11，Build ≥ 22621（新式右键菜单 + PackagedCom 需要） | 26300.9711，64 位 |
| 开发者模式 | 打开（`设置 → 系统 → 开发者选项`），或改用自签证书 | 已开（`AllowDevelopmentWithoutDevLicense = 1`） |
| 小米电脑管家 | 6.x（4.x / 5.x 也兼容，只是定位逻辑不同） | 6.0.2.30，`C:\Program Files\MI\XiaomiPCManager\6.0.2.30` |
| 构建环境 | `.NET 9 SDK`（只有自己编译才需要，用现成产物可跳过） | 9.0.320 |

检查开发者模式：

```powershell
(Get-ItemProperty 'HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\AppModelUnlock').AllowDevelopmentWithoutDevLicense
```

返回 `1` 即可。返回 `0` 或报错，就先开开发者模式，或者走第 6 节的证书路线。

## 2. 哪些文件放哪里

安装要分两个目录放，**不要混在一起**：

```
<仓库根>\src\SparsePackage\          ← 包目录（AppxManifest.xml 必须在这里）
├── AppxManifest.xml                 ← 清单
├── XiaomiImages\                    ← 12 张图，清单里的 Logo 都指向这里
├── Register.ps1
└── Unregister.ps1

%LOCALAPPDATA%\MiDropHelper\         ← 外部目录（ExternalLocation）
├── MiDropShellExt.dll               ← 右键菜单处理器（AOT 产物）
└── MiDrop.Helper.exe                ← 真正干活、调用电脑管家的进程（AOT 产物）
```

为什么分开：清单里的 `com:SurrogateServer Path="MiDropShellExt.dll"` 和 `Executable="MiDrop.Helper.exe"` 都是**相对路径**，注册时通过 `-ExternalLocation` 指定它们在哪个目录。这样包本身不用打包二进制，改代码只要换外部目录里的文件，不用重新注册。

`XiaomiImages\` 必须在**包目录**里，因为它是清单引用的包内资源，不受 `-ExternalLocation` 影响。少一张图会注册成功但磁贴/图标空白。

## 3. 从零到右键可用（实测命令序列）

下面每条都在本机跑过。`<仓库根>` 换成实际路径，本机是 `C:\Users\ME\.dsh\bot\workspace\MiDropShellExtForWindows11`。

### 3.1 准备外部目录并放二进制

```powershell
$pkg = '<仓库根>\src\SparsePackage'
$ext = Join-Path $env:LOCALAPPDATA 'MiDropHelper'
New-Item -ItemType Directory -Force -Path $ext | Out-Null

# 如果已经编译过，产物在 publish 目录；没有就先看 3.0 编译步骤
Copy-Item '<仓库根>\src\ShellExt\bin\x64\Release\net9.0-windows\win-x64\publish\MiDropShellExt.dll' $ext -Force
Copy-Item '<仓库根>\src\ShellExt\bin\x64\Release\net9.0-windows\win-x64\publish\MiDrop.Helper.exe'  $ext -Force

Get-ChildItem $ext -File | Select-Object Name, Length
```

预期看到两个文件：

```
MiDropShellExt.dll    2354688 B
MiDrop.Helper.exe     4439552 B
```

> 这两个是自包含 AOT 产物，不依赖目标机装 .NET 运行时。

### 3.0 编译（只有自己要改代码时才需要）

```powershell
cd <仓库根>
dotnet publish src\ShellExt\ShellExt.csproj -c Release -p:Platform=x64
```

产物落在 `src\ShellExt\bin\x64\Release\net9.0-windows\win-x64\publish\`。

> `Register.ps1` 不会帮你编译，也不会复制文件，它只做注册。

### 3.2 注册 sparse 包

```powershell
cd <仓库根>\src\SparsePackage
powershell -ExecutionPolicy Bypass -File Register.ps1 -DryRun   # 先空跑，检查路径对不对
powershell -ExecutionPolicy Bypass -File Register.ps1           # 真正注册
```

`Register.ps1` 默认外部目录就是 `%LOCALAPPDATA%\MiDropHelper`；要换地方就加 `-ExternalLocation <目录>`。

成功时打印：

```
已注册：MiDropShellExt.Sparse_1.0.0.0_x64__dsqz99bn8amy0
安装位置：<仓库根>\src\SparsePackage
检查 PackagedCom 索引（新式菜单的关键）：
  976D43D8-907F-46AF-B47F-07084C71A2F0 -> MiDropShellExt.Sparse_1.0.0.0_x64__dsqz99bn8amy0
  504d69c0-cb52-48df-b5b5-7161829fabc8 -> 不在 ClassIndex 里
```

### 3.3 自己复核一遍（两条硬指标）

```powershell
# ① 包身份拿到了
Get-AppxPackage -Name MiDropShellExt.Sparse | Format-List Name, PackageFullName, InstallLocation, IsDevelopmentMode, SignatureKind

# ② PackagedCom 索引里有我们的包（没有这条，新式菜单一定不出现）
Get-ChildItem 'HKLM:\SOFTWARE\Classes\PackagedCom\ClassIndex\{976D43D8-907F-46AF-B47F-07084C71A2F0}' |
    Select-Object -ExpandProperty PSChildName

# ③ 外部目录指向哪里（注册错了这里会露出来）
(Get-ItemProperty 'HKCU:\Software\Classes\Local Settings\Software\Microsoft\Windows\CurrentVersion\AppModel\Repository\Packages\MiDropShellExt.Sparse_1.0.0.0_x64__dsqz99bn8amy0').PackageRootFolder
```

预期：`IsDevelopmentMode : True`、`SignatureKind : None`、ClassIndex 下是包全名、`PackageRootFolder` 是 `%LOCALAPPDATA%\MiDropHelper`。

### 3.4 重启资源管理器

```powershell
Stop-Process -Name explorer -Force
```

任务栏闪一下是正常的，Explorer 会自动重启。

### 3.5 用

| 入口 | 怎么到 |
|---|---|
| 新式右键菜单 | 右键文件 →「应用扩展」子菜单 →「使用小米互传发送」（带图标） |
| 经典右键菜单 | 右键文件 →「显示更多选项」→ 两条「使用小米互传发送」中的一条 |
| 系统共享面板 | 右键文件 →「共享」→ 列表里的「使用小米互传发送」 |
| 开始菜单磁贴 | 开始菜单 → 应用列表 →「使用小米互传发送」（打开电脑管家「互联」页） |

## 4. 装完怎么确认真的能用

```powershell
# 点一次菜单后看日志
Get-Content (Join-Path $env:LOCALAPPDATA 'MiDropHelper\shellExt.log') -Tail 20
```

日志里应该出现 `LaunchHelper: key=... files=N` 和 `LaunchHelper: Process.Start ok`，并弹出「小米互传 · 发送」窗口，窗口里的文件名和文件大小要对得上。

只要**别点设备**，就不会真的发出任何东西，可以放心验证。

## 5. 卸载 / 回滚

```powershell
cd <仓库根>\src\SparsePackage
powershell -ExecutionPolicy Bypass -File Unregister.ps1
Stop-Process -Name explorer -Force
```

`Unregister.ps1` 只注销包，**不删文件、不动注册表里的其他键**。外部目录 `%LOCALAPPDATA%\MiDropHelper` 会留着，想彻底清干净就自己删：

```powershell
Remove-Item (Join-Path $env:LOCALAPPDATA 'MiDropHelper') -Recurse -Force
```

注销后预期：ClassIndex 里 `{976D43D8}` 那层消失，新式菜单里的条目消失，经典菜单里的条目从 2 条变 1 条（剩下那条是小米电脑管家安装时自己写进 HKLM 的，与本项目无关）。

## 6. 常见错误码对照

| 错误码 | 含义 | 处理 |
|---|---|---|
| `0x80073D54` | 找不到包的身份（`Package.Current` 为 null） | 不是安装失败。sparse 包的 exe 需要在自身 side-by-side 清单里写 `<msix publisher/packageName/applicationId>` 才拿得到身份；本项目**不依赖** exe 身份，`--share-files` 那条链路照常工作，可以忽略 |
| `0x800B0109` | 证书不在信任链里 | 开发者模式下注册 loose 包不会遇到；如果改用 `.msix`，先把自签 `.cer` 导入 `Cert:\CurrentUser\TrustedPeople` 再装 |
| `0x80073CF9` | 同版本包已注册 | 先 `Unregister.ps1`，再 `Register.ps1` |
| `0x80073CF6` | 清单结构不合法 | 检查 `AppxManifest.xml` 是否被编辑器改坏（编码、BOM、命名空间前缀），用 `git diff` 对回仓库版本 |
| `0x80073CF3` | 依赖或冲突校验失败 | 通常是外部目录里缺文件，重跑 `Register.ps1 -DryRun` 看它报哪个文件不存在 |

## 7. 正式安装进 `MiSmartShare\`（需要管理员，未实测）

> 这一节**没有在本机实测**，因为项目约定 `C:\Program Files\MI` 只读不写。以下命令仅供想彻底摆脱 sparse 包的人参考，执行前请自己确认风险。

`2026-11-10` 的实现方式是 sparse 包 + 外部目录，`C:\Program Files\MI\...\MiSmartShare\` 里的 `MiDropShellExt.dll`（76888 B，SHA256 `1680611EA3E34AF3C9BE5C4D83D6991C2DE279BC3CA53A33FDBB7B0AD1A543F6`）**原封未动**。

如果要把它换成我们编译的版本，步骤是：

1. **先备份原件**（必须有，否则无法回滚）
   ```powershell
   $mi = 'C:\Program Files\MI\XiaomiPCManager\6.0.2.30\MiSmartShare'
   Copy-Item "$mi\MiDropShellExt.dll" "$env:USERPROFILE\Desktop\MiDropShellExt.dll.orig"
   ```
2. **以管理员身份**打开 PowerShell（当前会话没有管理员权限，写入会被拒绝）
3. 覆盖 DLL，并**同步注册表指向的那份**——`HKCU\Software\Classes\CLSID\{504d69c0-...}\InprocServer32` 与 HKLM 里的 `*\shell\MiDropExtMenu` 都必须指向同一个文件
4. 重启 Explorer

风险：这一步等于改小米自己的安装目录，管家升级会被覆盖掉，而且当前会话的 Bot 没有管理员权限，做不了，只能由你手动执行。

## 8. 已知现象（不是故障）

- **经典菜单里有两项「使用小米互传发送」。** 一条来自小米电脑管家安装时写进 `HKLM\...\*\shell\MiDropExtMenu` 的动词，一条来自本 sparse 包的 `desktop4:fileExplorerContextMenus`。两条都能用。要去掉重复只能删小米的 HKLM 动词键（需管理员、等于改小米安装），本项目不做。
- **`Package.Current` 是 null。** AOT 产物没带 side-by-side `msix` 清单段，拿不到包身份。当前链路只用 `--share-files`，不依赖身份，属于已知且不影响使用。
- **包目录里的 `MiDropShellExt.dll` 是 `%LOCALAPPDATA%\MiDropHelper` 那份的副本。** 每次重建必须同步两份，否则新式菜单加载的是旧版。
- **日志里会出现 `StartShare packaged but helper missing: ...\src\SparsePackage\MiDrop.Helper\MiDrop.Helper.exe`。** 这是处理器按 `InstallLocation\MiDrop.Helper\` 探测探测包内 helper 的残留分支，探不到就会继续往下试，下一行 `StartShare candidate=...\MiDropHelper\MiDrop.Helper.exe exists=True` 才是真正用的那份。**这一行不影响功能**，看到不用管。
